What should happen when an AI agent is about to send a notification or permanently delete a record?

Compassionate AI Lab’s MCP Guardrail turns two of Dr. Sri Amit Ray’s Compassionate AI mottos into rules that can be tested. The No-Harm Principle sets limits on what the agent may do. Human dignity and choice mean a person can inspect and decide on an action before it runs.

Try three decisions

  1. Allow a read. The agent can retrieve a synthetic incident record when its request matches the tool’s schema.
  2. Review a notification. A local operator reviews the exact proposed action. An approval permits one matching retry in the same session.
  3. Block permanent deletion. The proposed action is denied before it reaches the mock backend.

Verify what happened

The local project includes a reproducible demo and test cases that check the mock backend’s actual effects. Its local status command verifies the audit chain. Request tracing links a tool call to its approval and recorded outcome without displaying raw tool arguments. The browser simulation illustrates the same flow using synthetic state in the page.
